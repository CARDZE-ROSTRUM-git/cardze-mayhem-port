# cardze-mayhem-port

[English](README.md) | **Русский**

> **BETA** — ранний, незаконченный порт. Ожидайте шероховатостей и недоделанных
> функций.

Настольный порт прошивки **PortaPack Mayhem** (HackRF One + PortaPack H2),
который нативно работает на Linux как приложение на SDL2.

## Проверено на

* Тестировалось **только** под оконным менеджером **niri** (Wayland). Другие
  окружения и композиторы не проверялись.
* Рассчитано и проверялось под **кибердеки** с дисплеем **7 дюймов 1024x600**.

Оригинальный интерфейс Mayhem используется **без изменений**: меню, виджеты,
шрифты, иконки и разметка 240x320 — это настоящий код прошивки. Заменены только
нижние слои:

| Прошивка (цель)            | Этот порт (хост)                                  |
|----------------------------|---------------------------------------------------|
| Потоки/события ChibiOS     | `std::thread` / mutex / condition variable        |
| Ядра LPC43xx M4 + M0       | потоки хоста                                      |
| LCD ILI9341 по SPI         | кадровый буфер RGB565 + текстуры SDL2             |
| Кнопки/энкодер             | клавиатура + экранный корпус PortaPack H2         |
| SD-карта FatFs             | обычная папка (`mayhem-sd/`)                       |
| RTL-SDR / PlutoSDR         | бэкенды libiio (`libiio`) и `librtlsdr`           |

Все **102 внешних приложения** из апстрима (вкладки RX / TX / Games / Utilities /
Settings / Debug) скомпилированы прямо в бинарник хоста.

## ⚠️ Поддержка SDR — прочитайте это первым

**Поддерживаются только два бэкенда SDR:**

* **PlutoSDR** (через `libiio`) — полный RX **и TX**
* **RTL-SDR** (через `librtlsdr`) — **только RX**

Поддержки HackRF / PortaPack по USB нет: это *порт*, а не эмулятор, поэтому
оригинальное железо HackRF не используется.

## ⚠️ TX не закончен (ALPHA)

Поддержка TX **экспериментальная и не проверена в эфире**. У главного
разработчика **пока нет PlutoSDR**, поэтому TX проверялся только против бэкендов
SDR в коде — **не подтверждён на реальном железе**. Считайте любую функцию TX
непроверенной. Протестированный путь — RX.

## Возможности

* Настоящий интерфейс прошивки Mayhem, масштаб x1 / x2 / x3, в рамке корпуса
  PortaPack H2.
* Клавиатура как альтернатива экранным кнопкам; мышь = сенсорный экран.
* Стартовое **окно настройки** до загрузки: выбор папки SD, устройства SDR,
  режима ввода (сенсор + экранные кнопки или **только сенсор**) и поворота окна.
* Поворот, выбранный в стартовом окне, **сохраняется** и применяется при
  следующем запуске.
* Файловая заглушка TX, когда нет SDR с передачей.
* По умолчанию плавающее окно; `F` / `F11` переключает безрамочный полный экран
  (корпус сохраняет пропорции, с чёрными полями по центру).
* Эмулируемая SD-карта — это папка, поэтому настройки, записи и плейлисты
  путешествуют вместе с приложением.

## Установка с нуля (Arch / EndeavourOS)

```sh
# 1. Зависимости сборки + библиотеки SDR
sudo pacman -S --needed base-devel cmake git pkgconf sdl2 sdl2_image \
    rtl-sdr libiio libad9361-iio python

# 2. Получить этот порт
git clone https://github.com/CARDZE-ROSTRUM-git/cardze-mayhem-port.git
cd cardze-mayhem-port

# 3. Получить апстрим прошивки на зафиксированном коммите
git clone https://github.com/portapack-mayhem/mayhem-firmware.git \
    third_party/mayhem-firmware
git -C third_party/mayhem-firmware checkout 77798cb09f227de5c58dea48899ddb7448b44a07

# 4. Сборка
mkdir -p build && cd build
cmake ..
cmake --build . -j"$(nproc)"

# 5. Запуск
cd .. && cp -f build/mayhem-desktop . && ./run.sh
```

### Аналог для Debian / Ubuntu

```sh
sudo apt install build-essential cmake git pkg-config libsdl2-dev sdl2-image \
    librtlsdr-dev libiio-dev libad9361-dev python3
```

Затем повторите шаги 2–5 выше.

## Пакеты / требования

| Пакет          | Для чего                        |
|----------------|--------------------------------|
| `cmake`, `git`, `pkgconf` | система сборки       |
| `base-devel` / `build-essential` | инструментарий C/C++  |
| `sdl2`         | окно, ввод, звук               |
| `sdl2_image`   | загрузка изображений (иконки/экраны) |
| `rtl-sdr`      | бэкенд RTL-SDR (только RX)     |
| `libiio`       | бэкенд PlutoSDR (RX + TX)      |
| `libad9361-iio`| RF-помощники PlutoSDR          |
| `python`       | `tools/gen_external.py`        |

Бэкенды RTL-SDR / PlutoSDR компилируются **только если найдена их библиотека**.
Без них приложение всё равно собирается и работает с файловой заглушкой TX.

## Запуск

`run.sh` лежит рядом с бинарником и его эмулируемой SD-картой:

```sh
./run.sh
```

Он задаёт `MAYHEM_SD` на соседнюю папку `mayhem-sd/` и выбирает разумный
видеодрайвер SDL. Расположение SD можно переопределить:

```sh
MAYHEM_SD=~/my-mayhem-sd ./run.sh
```

### Управление с клавиатуры

| Клавиши               | Действие                        |
|-----------------------|---------------------------------|
| Стрелки               | D-pad (вверх/вниз/влево/вправо) |
| Enter / Space         | Выбрать                         |
| Esc                   | Назад                           |
| Колесо мыши / `<` `>` | Энкодер                         |
| `1` / `2` / `3`       | Масштаб x1 / x2 / x3            |
| `R`                   | Повернуть корпус                |
| `F` / `F11`           | Переключить полный экран        |
